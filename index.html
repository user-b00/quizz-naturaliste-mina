Comment s'entraîner ?

Choisis une option et une catégorie, puis sélectionne un mode. Le quiz textuel est disponible tout de suite. Le mode QCM est conçu pour afficher aléatoirement une photo issue du lot vérifié de chaque espèce ; les photos sont recherchées automatiquement auprès d’iNaturalist (connexion Internet requise).

Pour retrouver la progression sur un autre appareil, il faudra exporter les résultats ou ajouter une synchronisation dans une future version.
